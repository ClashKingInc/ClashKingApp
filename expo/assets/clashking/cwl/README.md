# CWL header artwork

These eight bundled WebP files derive from original Supercell map artwork.
Source: local `map.sc` and textures, game fingerprint version `18.600.1`.
The user confirmed source indices 0–7 represent Bronze, Silver, Gold, Crystal,
Master, Champion, Titan, and Legend respectively.

Each header crops the top 1700 × 690 pixels of the reconstructed rectangular map,
resizes proportionally to 1100 pixels wide, and uses WebP quality 86.
No AI-generated art is included. Full-map spacing is a reconstruction, not a claim
of exact game runtime placement. Navigation never waits on a remote header image.

Original artwork remains Supercell's property. These are app-local derivatives,
not a public asset-pipeline release.
