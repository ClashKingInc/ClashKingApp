# Player Info — Electro Dragon

User-selected concept 3, 22 October 2026. Generated with the built-in image tool,
using the real `clashking_assets/assets/troops/electro_dragon/icon.webp` as a
reference. This is generated artwork, not official Supercell artwork.

Prompt: a classic blue Electro Dragon resting on a broad rocky ledge above a
home-village valley at blue hour. Preserve the oversized square snout, short
horn, pale-cyan eyes and chunky scales. Quiet central foreground for player
identity; minimal electricity; no builders, barbarians, banners, text or UI.
Full prompt is saved in the task's `player-background-prompts.txt`.

Source: task visualization `player-option-3-dragon.png`.

every tab, including Builder Base. Existing cover crop and separate tint/fade

## Quiet background revision

`player-electro-dragon-quiet-v3.webp` is the current selected asset on all tabs
and sizes. The user found the distant village distracting. A built-in image
edit removed the buildings, warm window lights and their reflections, replacing
them with wooded terraces. The dragon, square framing, moon, river, waterfalls
and foreground composition were retained. No code-level crop or tint changed.
Earlier versions are retained as source history, not selected by the app.
