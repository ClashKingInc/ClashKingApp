# War detail backdrop

`battlefield.webp` is the unmodified `Player_war_bg` export from Supercell's
`background_war.sc`, extracted with this workspace's existing Go asset exporter.
The review manifest is in `war-redesign-assets/manifest.json` alongside the local
2026-10-20 war redesign review. No AI-generated imagery or baked-in app text.

Bundled locally so navigation does not wait for a scenery download. Render with
proportional cover cropping, a readable scrim, and the existing page fade.
Original artwork remains Supercell's property; no public asset release was made.
