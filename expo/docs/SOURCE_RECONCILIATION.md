## Differences that deliberately remain

1. **Shared API transport.** Feature services now use the browser-safe shared client and `/expo` contracts, not the original raw request class. Only `expo/src/core/api/client.ts`, `expo/src/core/api/client-observability.test.ts`, and `expo/src/core/__tests__/api-client.test.mjs` are absent from the original file inventory; their purpose is replaced by shared-client, observability, and contract tests. Data responses use the current authoritative API fields, not compatibility aliases. Current service origins remain intact.
2. **Explicit retirements.** Connected-app approval and Legend attack/defense notification settings remain removed by user direction even though fetched main still contains stale Legend controls. General Legend statistics and supported notifications remain. `LEGEND_NOTIFICATION_RETIREMENT.md` records exact remote file links; no new notification persistence/provider work was added.
3. **Builder Hall counts were not working.** The recorded original API returns 501. The old App placed that request in the same combined load as supported Town Hall/league counts. The corrected App omits only the unavailable request so it cannot erase the supported results; it does not invent zero counts or a provider.
4. **Export requests follow the actual API.** Original App export callers sent several unsupported filters. Current original Go `internal/routes/exports.go` blob `ad279c6366c6a09c32289eca755d5273f03823f1`, handler lines 161–170, and `internal/models/v2/exports.go` lines 3–8 accept only `tag`, `timestampstart`, `timestampend`, and `limit`. The typed App request keeps those supported fields. Filters such as war type/stars/season/multiple-player tags were not backend capabilities and are not silently added. Display filtering remains a separate local behavior; exports are not claimed to honor unsupported filters.
5. **Transport failures remain visible.** Reconciliation caught saved-rewrite cases where transport failure looked like empty data. Clan capital loading now preserves successful clans when another returns an ordinary API error, search still surfaces offline transport failures, and ranked-group loading no longer swallows transport failures. Focused tests distinguish API errors from a missing connection.
6. **Compiler/test/generated artifacts.** TypeScript 6 retains compiler APIs, TypeScript 7 performs semantic checking, and Effect remains v4. Jest and source-structure tests are adapted to those tools and the shared contracts. The production license inventory was regenerated from the installed package tree; generated native projects were not blindly copied. The helper E2E inbox Worker only retains its saved toolchain change; its runtime source is unchanged and was not deployed.
7. **Plans are not features.** The restored original `docs/0.4.2-deep-links-and-network-plan.md` explicitly marks proposed AVIF, adaptive-network, and performance-benchmark work as planning-only. Those proposals were not converted into new product scope. The original deep-link guide was preserved as source context.
